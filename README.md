# Basic Network Sniffer

## Overview
This project was developed as Task 1 of my Cyber Security Internship at Arch Technologies. It demonstrates basic network packet sniffing and packet analysis using Python in a controlled environment.

## Tools Used
- Python
- Visual Studio Code
- Packet analysis output

## Project Files
- `sniffer.py` — Python source code for the network sniffer.
- `packet_analysis` — Packet analysis results.
- Screenshot — Evidence of the practical output.

## Learning Outcomes
- Understanding basic network packet sniffing.
- Learning how network packets can be captured and analyzed.
- Exploring the role of packet analysis in cybersecurity.
- Understanding the importance of authorized network monitoring.

## Security Note
This project is intended for educational purposes and should only be used on networks where monitoring is authorized.
